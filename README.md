## ⚙️ How It Works

One of the main things I wanted was to avoid editing the code every time I wanted to update my portfolio.

So I built a small admin system:

```text
Admin Panel
     ↓
Next.js API
     ↓
MongoDB
     ↓
Live Portfolio
```

I can update things like my introduction, projects, links, and project demo videos directly from the admin panel.

## 🚀 Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
MONGODB_URI=
```

Add your MongoDB connection string and start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
